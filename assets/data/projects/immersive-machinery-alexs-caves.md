# Overview

A small Minecraft Forge mod for 1.20.1 adding integration between the mods "Immersive Machinery" and "Alex's Caves".

# Description

## Features

* Allows the Copper Fin submarine from Immersive Machinery to be seen by Hullbreakers in the depths biome from Alex's Caves.
* All damage applied to the player while inside the Copper Fin is transfered to it instead.

## Mods required

* [Immersive Aircraft (1.4.0)](https://www.curseforge.com/minecraft/mc-mods/immersive-aircraft)
* [Immersive Machinery (0.2.0)](https://www.curseforge.com/minecraft/mc-mods/immersive-machinery)
* [Alex's Caves (2.0.2)](https://www.curseforge.com/minecraft/mc-mods/alexs-caves)
