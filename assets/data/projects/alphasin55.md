# Overview

## Context of Galaxy 55

Galaxy 55 was a Minecraft-like game developed by MotionTwin in 2012 before Minecraft's adventure mode was released. The game featured a customizable ship that you coud use to travel to procedural planets to gather resouces, and a 3D crafting system.

The game was cancelled during it's beta phase after Minecraft's adventure mode was released.

[](https://www.youtube.com/embed/XRQ6XE6K-wQ)

## AlphaSIN55 mod

This a reimagined recreation of Galaxy 55 made in Minecraft Java Edition as a mod. I've benn working on this for a long time in my spare time, but although progress is slow, it already contains some of the core features of Galaxy 55.

Current features:

* More than 200 blocks with unique functionality.
* 3D crafting system with shaped and shapeless recipes.
* Mining laser with custom inventory to store charges.

Planned features for the initial release:

* Structure generation in the Overworld to gather initial resources and a portal room.
* 1 dimension representing the initial planet of Galaxy 55.

Planed features for the future:

* 4 more dimensions representing each of the planets.
* Customizable ship with working on-board computer.
* UI and menus to travel through the galaxy.
* Mobs and NPCs?
