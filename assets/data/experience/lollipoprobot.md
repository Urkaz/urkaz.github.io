# Playtesting

Playtesting and quality assurance support for the porting process on PS4, Xbox One, and Nintendo Switch, testing gameplay, performance, and platform-specific features to detect bugs and regressions. Issues were reported and tracked using tools such as Jira, Mantis, Bitbucket, and GitHub. Platform-specific debugging tools were used to analyze crashes and validate fixes in collaboration with designers and programmers.

In some cases, we were able to provide feedback and contribute to the design of control schemes, maintaining close communication with one of the main clients, BlitWorks, among others.

# Compliance Testing

In addition to playtesting, I performed compliance testing by verifying that the games met the requirements of TRC, XRC, and Nintendo Guidelines. This involved systematically checking platform-specific rules, certification checklists, and edge cases to ensure that each title fulfilled all technical and functional requirements needed to pass certification and be approved for release on their respective platforms.

# Script Automation

Developed and maintained automation tools to streamline testing tasks using custom .bat scripts that interfaced with the command-line tools of each platform. These scripts enabled quick execution of common actions such as exporting save data, copying crash reports, launching builds, and running input macros, significantly reducing manual work and speeding up repetitive testing and debugging processes.
